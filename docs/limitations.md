# 已知限制与未实现功能

本版本是可运行的小型数据库引擎，不是成熟数据库的替代品。以下边界是设计的一部分，不应通过功能名称推断更大的能力。

## 存储与恢复

- 固定 4096 字节页面；单条 Heap 记录最多 4052 字节，没有 overflow/LOB 页面。
- B+ Tree 键最多 512 字节；超长索引值会报错。仅单列索引，主键为单列。
- WAL 使用全页 after-image 和同步提交；写放大高于细粒度日志。
- 事务私有页面保留在内存，不能溢写到独立临时空间。大事务内存不受 Buffer Pool 容量约束。
- 校验和用于检测意外损坏，不是密码学认证；没有自动备份、复制、时间点恢复或任意损坏修复。
- 不能在运行中拷贝一半数据库文件作为一致备份；应关闭全部连接后保存数据与 WAL。
- 文件格式没有跨版本迁移工具。升级代码前应备份；兼容性以格式版本检查和测试为准。
- 故障注入测试覆盖进程异常退出，不宣称已完成真实断电、磁盘控制器故障或所有 I/O 失败组合验证。

## 并发与资源

- 数据库级严格共享／排他锁，所有写事务串行；长读事务阻塞写事务。
- 死锁处理依赖等待超时及回滚，没有等待图检测；没有 MVCC、行级锁或并发写索引修改。
- 单个 Connection 应由一个线程使用；线程间共享 Database，分别创建 Connection。
- PreparedStatement 依赖原 Connection 生命周期，当前没有绑定参数。
- 扫描结果、排序、JOIN 和聚合会物化到内存，没有外部排序、哈希分区溢写或内存配额。
- 查询优化是规则式的索引选择；没有成本模型、统计直方图或通用连接顺序优化。
- `EXPLAIN SELECT` 目前实际执行只读查询后返回执行器计划，不能用于低成本估算大查询；不会执行 DML。
- Heap 插入会搜索可用空间，未维护专门的 free-space map；大表顺序插入不是成熟引擎的吞吐水平。

## SQL 与接口

- 完整支持的语法见 [SQL 文档](sql.md)。没有外键、复合主键/索引、ALTER、DROP INDEX、子查询、CTE、窗口函数、DISTINCT、HAVING、UNION 或外连接。
- INTEGER 为 int64；DOUBLE 为有限双精度；没有 DECIMAL、DATE/TIME、二进制大对象或可配置字符校对。
- 字符串长度、LIKE 和排序按字节处理；大小写函数不实现 Unicode 全量大小写折叠。
- CLI 表格按字节计算宽度，宽 Unicode 字符可能显示不齐。
- 错误以异常和诊断字符串报告，尚未建立覆盖所有模块的稳定数值 ErrorCode/Status ABI。
- 无网络协议、用户权限、认证、加密或多进程服务器。数据库文件操作由本机程序负责。

## 测试结果的解释

自动化测试通过表示列出的断言和故障场景在指定环境下通过，不等于无缺陷证明。性能报告来自本机和虚拟机实际运行，包含 OS 文件缓存和虚拟化影响，不与其他数据库或硬件直接比较。
