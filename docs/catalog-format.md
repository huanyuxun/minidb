# Catalog 与 Tuple 编码

所有整数均显式序列化为 little-endian，不落盘 C++ 对象布局、指针或 STL 容器。

## Catalog 页链

页 0 是目录链起点，每页先保留公共 32 字节页头；其格式和 CRC 见 [存储文档](storage.md)。

| 偏移 | 长度 | 内容 |
|---|---|---|
| 32 | 4 | 目录标识 0x31415443；全零表示新数据库空目录 |
| 36 | 4 | 下一页 PageId，UINT32_MAX 表示末页 |
| 40 | 4 | 本页目录载荷字节数，最大 4052 |
| 44 | 可变 | 目录序列化字节流的一个片段 |

串接载荷得到：版本 u32（1）、数据库名称 string、表数量 u32，随后依次为每张表的名称、Heap 首 PageId、列数量和列定义、索引数量和索引定义。string 编码是 u32 字节长度与原始字节。

列定义包含名称 string、类型 u8（0 INTEGER / 1 DOUBLE / 2 VARCHAR）、最大长度 u32、非空 u8、主键 u8。索引定义包含名称 string、列序号 u32、根 PageId u32、唯一性 u8。页链循环、长度越界、不合法类型和索引列号都会报错。

目录更新在同一 PageTransaction 中重写页链，复用已有页、分配不足的页、释放多余页。DDL、索引根变化和数据记录由同一 WAL 提交原子持久化。

## Tuple

Tuple 从列数 u32 开始，每列先写类型标签 u8：0 NULL、1 int64、2 IEEE754 double、3 string、4 bool。整数和浮点通过 bit_cast 转换为 u64 再逐字节写入；bool 为一个字节。SQL 表列限制为 INTEGER、DOUBLE、VARCHAR，bool 主要用于表达式结果。

## 索引键

索引不写入 NULL。每棵树只索引一列，故无需在键内混合类型。int64 翻转符号位后以 big-endian 编码，使字节序与整数序一致；double 对正数翻转符号位、负数逐位取反后 big-endian 编码；正负零统一为正零。字符串使用原始字节。重复键由 RID 作为第二排序字段区分。主键唯一性由事务持有排他锁时先查询索引再插入保证。

混合 INTEGER/DOUBLE 谓词只有能够安全转换时才使用索引界限，否则使用全扫描与精确表达式比较，避免大于 2^53 的整数被 double 舍入导致漏行。
